# MDEditor 官网升级规划

## 一、整体定位

将现有单页下载站升级为「极简风格的产品官网」，核心目标：
- 让访问者第一时间理解产品全貌
- 建立"从写作到交付，一步到位"的认知
- 激发下载冲动

## 二、视觉风格

| 维度 | 方向 |
|------|------|
| 整体气质 | 极简、干净、专业、轻量工具感 |
| 配色 | 白底/浅灰为主，少量品牌色点缀 |
| 排版 | 大留白、大标题、短文案、产品截图为主视觉 |
| 动画 | 克制微动画：线条流光、节点轻浮动、卡片淡入 |
| 按钮 | 直接说"免费下载"，降低心理门槛 |

延续现有极简风格，不做花哨视觉，提升质感和信息层次即可。

## 三、导航结构

```
首页 / Markdown 编辑器 / AI 创作与设计 / 关于
```

## 四、各页面内容骨架

### 1. 首页

> 职责：建立全局认知 + 引导下载

| 区块 | 内容 |
|------|------|
| Hero 区 | 主标题「写作到交付，一步到位」+ 副标题「从 Markdown 编辑到 AI 长图文、PPT，一个桌面工具搞定全流程」+ 下载按钮 |
| 工作流轨道图 | 极简横向流程图：`资料导入 → Markdown 编辑 → AI 写作/设计 → 长图文/PPT → 多格式交付`，带微动画（线条流光 + 节点浮动） |
| 核心价值卡片 | 3-4 张卡片，每张一个核心卖点：专业编辑 / AI 创作 / 设计交付 / 安全可靠 |
| 特性亮点 | 智能导入、草稿安全、版本历史、多格式导出等差异化能力（图标+短文案） |
| 底部 CTA | 再次出现下载按钮 + 引导语 |

### 2. Markdown 编辑器

> 职责：证明编辑能力的深度，不是又一个平庸 MD 工具

| 区块 | 内容 |
|------|------|
| Hero 区 | 标题「专业级 Markdown 编辑体验」+ 产品截图（三栏：源码/文档/预览） |
| 三种编辑模式 | 源码编辑 / 所见即所得 / 渲染预览，图标+短文案+截图 |
| 编辑器亮点 | 源码与文档双向高亮定位、行号/括号配对/缩进线、查找替换、大纲导航 |
| 富内容支持 | 表格、Mermaid 图表、LaTeX 公式、代码块高亮、Emoji、脚注、Callout |
| 多文档管理 | 多标签页、文件树、拖拽排序、拖拽打开 |
| 智能导入 | URL / HTML / DOCX / PPTX → Markdown |
| 文档安全 | 草稿箱自动保存、版本历史、关闭确认、工作区恢复 |
| 底部 CTA | 下载按钮 |

### 3. AI 创作与设计

> 职责：展示 AI 能力的独特价值——写作、长图文、PPT

| 区块 | 内容 |
|------|------|
| Hero 区 | 标题「AI 驱动，从内容到成品」+ 产品截图 |
| AI 写作 | 多轮澄清需求 → 生成完整 Markdown 草稿，不是瞎写 |
| 呼叫老鸟 | 选区级 AI 助手：改写/润色/翻译/解释/结构化 |
| AI 长图文 | Markdown → 完整 HTML 长页，支持多种设计师主题、内容策略、设计强度 |
| AI PPT | Markdown → 演示型幻灯片，自动分页、多版式、切页动画、全屏播放 |
| 可视化编辑 | AI 生成后可视化调整 + 局部美化，不用推翻重来 |
| 多格式导出 | HTML / PDF / 长图 / PPTX，进入真实交付链路 |
| 底部 CTA | 下载按钮 |

| 更新日志 | 最近几个版本的核心更新 |

## 五、技术方案建议

| 维度 | 建议 |
|------|------|
| 框架 | 保持纯静态站（HTML/CSS/JS），不引入重框架，保证加载速度 |
| 路由 | 多页面各自独立 HTML 文件，共享 header/footer 通过 JS 组件化 |
| 动画 | CSS Animation + 少量 JS（Intersection Observer 触发滚动动画） |
| 响应式 | 移动端适配，但桌面端优先 |
| 部署 | 继续用 Cloudflare Pages |

## 六、需要你补充的资料

开始开发前，以下内容需要你准备：

1. **产品截图**：编辑器三栏截图、AI 写作界面、AI 长图文效果、AI PPT 效果、导出效果
2. **品牌色**：确认主品牌色（目前偏黑灰，是否需要一个点缀色？）
3. **下载文件**：最新版本的安装包路径
4. **更新日志**：最近 2-3 个版本的核心更新内容
5. **联系方式**：邮箱/社交账号/反馈入口

## 七、开发优先级

1. 首页（最重要，访问者第一印象）
2. Markdown 编辑器页
3. AI 创作与设计页
4. 关于页
